Deleting a theme, or turning it inactive, does not affect letters that already reference it — every letter saves its own copy of the theme's image or style at the moment it's written. Active only controls whether a theme is offered as an option on the "Write a letter" page going forward; turning a theme inactive is the safe way to retire it without breaking anything already written. Delete removes the theme document itself — also safe for existing letters, but permanent for the theme record (you'll lose the ability to reuse or re-fetch its settings here).
